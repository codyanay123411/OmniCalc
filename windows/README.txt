OmniCalc - free all-in-one calculator
=====================================

Windows (recommended):
  1. Unzip this folder somewhere permanent, like Documents\OmniCalc
     (don't run it from inside the zip).
  2. Double-click "Install OmniCalc.cmd".
     This adds OmniCalc to the Start menu and Desktop. It opens in its own window.
     If Windows shows "Windows protected your PC", click More info -> Run anyway.
  3. Optional: double-click "Make OmniCalc Default.cmd" to make it your PC's
     Calculator (Start menu "Calculator", the keyboard Calculator key) and
     optionally remove the built-in Windows Calculator.
     "Restore Windows Calculator.cmd" undoes that.

Mac, Linux, Chromebook, or no install:
  Just double-click OmniCalc.html. It opens in your web browser and works offline.

What's inside: calculator, graphing, unit math, time, money, dates, algebra
(with step-by-step working), calculus, geometry, vectors, probability,
statistics, number theory, matrices, science formulas, rifle & mortar math,
and a Study tab: practice problems with worked steps, quizzes, flashcards
with spaced repetition, formula sheets, a focus timer and progress tracking.

Tip: the "Self-test" button (bottom-left) checks that every feature works.
Everything runs on your own computer; nothing is sent anywhere.
